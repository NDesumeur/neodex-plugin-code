# Code secret

Trouve le code de 4 couleurs en 10 essais. Les fiches noires disent les bonnes couleurs bien placées, les blanches les bonnes couleurs mal placées.

Le jeu cache 4 couleurs parmi 6. Propose une ligne : il répond par des fiches noires (bonne couleur, bonne place) et blanches (bonne couleur, mauvaise place). 10 essais pour trouver.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Code secret → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
